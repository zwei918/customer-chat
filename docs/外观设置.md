# 聊天页外观设置

运营中台和访客聊天页各改各的名字、头像。

## 外观设置（运营中台）

只改后台侧栏、顶栏：`GET/POST /admin/api/ops`、`/admin/api/ops-logo`。文件在 `uploads/ops/logo.*`（不进 git）。

在线状态、对话区背景仍走 `GET/POST /admin/api/settings`，会下发到聊天页。

## 客服通道（访客聊天）

- 机器人名称、欢迎语、发图/文件/语音：`PUT /admin/api/brands/{id}`
- 机器人头像：`POST/DELETE /admin/api/logo`，文件 `uploads/brand/logo.*`
- 客户头像图库：`/admin/api/visitor-avatars`，文件 `uploads/visitors/`（不进 git）。每个访客随机抽一张并记住。
- 欢迎语下面的问题和答案在「快捷回复」：`/admin/api/canned`
- 聊天页公开接口：`GET /api/widget`（带 `X-Visitor-Id` 时返回该访客的 `visitor_avatar_url`）
