# 后台视觉（Figma → 客服小美）

稿来源：`MDM2CpwUHaFKCnMa7dcQOQ`

只借骨架。看板、顶栏按钮、右侧栏都接客服小美自己的 H5 聊天数据。

| 节点 | 用途 |
|---|---|
| `1:3` | 桌面：深色侧栏 + 白顶栏 + 色块看板 |
| `1:2287` | 手机收起：顶栏汉堡，内容单列 |
| `1:3979` | 手机汉堡打开：255px 深色抽屉 + 关闭 |
| `1:4255` | 列表图标打开：320px 右侧栏（动态 / 访客 / 设置） |

## 顶栏七个图标（按聊天业务）

| 图标 | 功能 |
|---|---|
| 铃铛 | 客户新消息下拉，点一条进该访客会话 |
| 列表 | 右侧今日动态栏（今天 / 更早） |
| 信封 | 最近访客会话下拉 |
| 语言 | 简体中文（聊天页尚未多语言） |
| 太阳 | 仅切换后台深浅色，不影响聊天页 |
| 头像 | 在线状态、外观设置、退出登录 |
| 九宫格 | 看板 / 会话 / 访客 / 外观 / 打开聊天页 |

## 运营看板

数字来自 `/admin/api/stats`：累计访客/消息/会话、今日对比昨日、客户消息 vs 小美回复、近 14 天柱状图、客户消息关键词。不使用稿里的交通图、日期选择器和社交网站色块。
