# 在线客服平台架构

「客服小美」是默认品牌/机器人昵称，产品边界是对标美洽 / 智齿 / Crisp 的在线客服平台。

## 三套表面

- 访客通道：`index.html`（H5）。名称、机器人头像、欢迎语、发图/文件/语音、客户头像来自「客服通道」；欢迎语下的问题和答案来自「快捷回复」。
- 坐席工作台：`/desk`（`desk.html`）。待接 / 全部 / 我的，认领、转接、回复、结束。
- 运营中台：`/admin`（`admin.html`）。看板、客服管理、客服通道、路由排班、快捷回复、报表。外观设置只改中台自己的名字和头像。

## 数据模型

表从第一天带 `workspace_id`（当前只跑工作区 1）。会话状态：`bot | queued | assigned | resolved`。消息 `sender_type`：`visitor / bot / agent / system`。

预留：`tickets`、`audit_log`；通道字段 `channel` 默认 `web`。

## 一期到三期已落地

- 工作区、坐席账号、角色（环境超管 + staff）
- 品牌驱动访客端；聊天气泡客户右、坐席/机器人左
- 转人工关键词、认领/转接、人工回复；人工接入后 AI 停口
- 技能组、轮询/饱和度/熟客、上下班、快捷回复、满意度、坐席报表
